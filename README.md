# 🧮 Калькулятор детской стипендии

Простой и удобный HTML-калькулятор для расчёта стипендии ребёнка по оценкам.  
Всё работает **локально** — просто скачайте и откройте в браузере.

---

## 📌 Возможности

- ➕ Добавляйте оценки (5, 4, 3, 2) нажатием кнопок.
- 🔄 Сброс всех оценок одним кликом.
- ⚙️ Настройка:
  - Имя ученика
  - Месяц
  - Базовая сумма
  - Штраф за плохие оценки (>1)
  - Порог четвёрок для вычета ⅓
  - Доли вычета за 1 плохую оценку и за несколько
- 🧾 Анимированная печать чека с детальным расчётом.
- ❓ Встроенная справка по всем элементам.
- 📸 Сохранение чека через стандартный скриншот устройства.

---

## 🚀 Как использовать

1. Скачайте файл `index.html` из репозитория.
2. Откройте его в любом браузере (Chrome, Firefox, Edge, Safari).
3. Нажимайте кнопки оценок, настраивайте параметры и жмите «ИТОГ».
4. Чек появится с анимацией — его можно закрыть или сделать скриншот.
